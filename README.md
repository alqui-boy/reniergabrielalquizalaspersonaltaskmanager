## Features

- Delete Task
- Update Status

## Overview
This project is a simple Laravel-based personal task manager that allows users to create, view, edit, delete, and update the status of tasks. The application follows the Laravel flow of Route → Controller → Model → Database → Blade views.

## Requirements Covered
- Laravel
- Routes
- Controller
- Model
- Blade Views
- Database migration

## Run the Project
1. Open the project folder.
2. Run `composer install`.
3. Run `php artisan migrate`.
4. Run `php artisan serve`.
5. Open the browser at `http://localhost:8000`.

## Notes
This project uses SQLite for local development and can be switched to MySQL or another Laravel-supported database by updating the `.env` file.
